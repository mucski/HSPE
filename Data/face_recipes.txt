# HSPE face recipes - read by the Face window (Reload recipes re-reads this file, no restart needed).
#
# [mood <Name> <angle> [female|male]]   angle in degrees on the mood pad: 0 = right, 90 = top, counter-clockwise
# [neutral [female|male]]               the default face; takes the weight a partial mood leaves
# [vowel <Name> [female|male]]          replaces the MOUTH lines of the mood
# [point <Name>]                        a draggable point on the face diagram (bone / at / twin / x / y lines)
#   x+|x-|y+|y- pattern <part> <key> <w>        a blend shape driven by one drag direction (weight at a full drag)
#   x+|x-|y+|y- shape <part> <mesh> <name> <w>  the same with one exact shape; a point needs no bone if it only has these
#                                       "at" is as seen from the front: her left (_L) sits on the diagram's right
#
# <part> pattern <key> <weight>         part = brows / eyes / mouth. The key is applied to every face mesh of that part
#                                       that has it: eyes = head eyes + lashes + tears, brows = brows mesh,
#                                       mouth = head mouth + teeth + tongue + beard. Weight 0..100.
# <part> shape <mesh> <exact name> <w>  one exact blend shape (mesh = head brows lashes teeth tongue tears1 tears2 beard)
# <part> bone <bone> pos|rot x y z      bone offset from its rest pose (local; rot in degrees). "*_J_X" = cf_J_X or cm_J_X
# ignore <key>                          never touch this key (face SHAPE keys that share a group with expressions)
#
# When a part is used, every other key of that part is written 0 (the game's defaults sit at 100).
